# 术语表

- **HTTP**：浏览器和服务器通信时共同遵守的规则。
- **API**：后端对外提供的功能入口，例如查询数据或保存评分。
- **JSON**：前后端常用的数据格式。
- **端口**：一台电脑上区分不同服务的编号，例如前端 5173、后端 3000。
- **开发代理**：开发时由 Vite 把 `/api` 请求转发给后端，页面不必写死后端地址。
- **数据库**：持久保存业务数据的系统，程序重启后数据仍存在。
- **ORM**：用 TypeScript 对象操作数据库的工具，本项目后续使用 Prisma。
- **Prisma Client**：根据数据库模型生成的 TypeScript 数据库操作代码。
- **迁移**：用可追踪的文件修改数据库表结构。
- **Controller**：接收 HTTP 请求并读取参数，不负责复杂业务规则。
- **Service**：处理业务规则，并调用数据库或其他服务。
- **依赖注入**：由框架创建并提供 Service，Controller 不需要自己实例化它。
- **DTO**：描述接口允许接收哪些字段以及字段类型的数据类。
- **ValidationPipe**：NestJS 在请求进入 Controller 前自动执行 DTO 校验的组件。
- **异常过滤器**：集中捕获异常，并把不同错误转换成统一响应格式的组件。
- **业务错误码**：程序用来区分失败原因的稳定标识，例如 `SCORE_OUT_OF_RANGE`。
- **认证**：确认调用者是谁，例如通过用户名和密码登录。
- **授权**：确认已经登录的用户是否有权执行某项操作。
- **JWT**：带签名的身份凭证，后端可验证内容是否被篡改以及是否过期。
- **Guard**：NestJS 在请求进入 Controller 前执行认证或权限检查的组件。
- **密码摘要**：通过单向算法得到的密码验证数据，数据库不保存用户的明文密码。
- **环境变量**：放置不同环境配置的方式，例如端口和数据库地址。
- **构建**：把 TypeScript、React 等源码转换成可部署产物。
- **Nginx**：托管前端静态文件，并把 API 请求转发给后端。
- **Docker 镜像**：包含程序及运行环境的可复制软件包。
- **Docker 容器**：镜像实际运行起来的实例。
- **Volume**：Docker 管理的持久化空间，删除容器后数据库文件仍可保留。
- **CI/CD**：自动检查、构建和部署代码的流程。
- **日志**：程序运行时留下的事件记录，用于定位故障。
